# Combined-denominator dilution — PrEP + PLWH exposed population

Generated by `src/feasibility/dilution_plwh.py`. Reproduce:

```
python3 -m src.feasibility.dilution_plwh
```

## Why this exists

The published dilution gate (`dilution.py`) indexed the doxy-PEP-exposed
population on AIDSVu **male PrEP users only**. The DoxyPEP trial enrolled two
populations offered doxy-PEP — HIV-negative people on PrEP **and** people living
with HIV (PLWH). Indexing `f` on PrEP users alone undercounts the exposed and
biases `RR_needed` **upward** (toward "undetectable"), i.e. in favour of the
paper's own conclusion. Correcting it pushes `RR_needed` down, against the
conclusion; that is why it is worth doing.

## Primary specification (decided 2026-09-08)

**`msm_frac = 1.00` is PRIMARY** — every male PLWH is counted as doxy-PEP exposed.
Rationale: it needs no external MSM-fraction parameter and is maximally generous
to detection. `msm_frac ∈ {0.50, 0.66, 0.80}` are sensitivity, not headline.
PrEP-only indexing is **rejected** as non-conservative (it biases `RR_needed` up,
in favour of the paper's conclusion).

```
exposed = ( male_prep_users + msm_frac · male_plwh_cases ) · uptake · dose
f       = exposed · kappa / population
RR_needed = 1 + MDE/(f·R0),   MDE = (z_{α/2}+z_power)·sqrt(2·R0·(1-R0)/N)
panel:    N_eff = G·T·N / DEFF
```

Must be stated explicitly:
- **Male PLWH is a prevalence STOCK**, not new-diagnosis flow.
- AIDSVu state prevalence carries **no transmission-category split**, which is why
  `msm_frac = 1.00` is used as primary rather than a fractional estimate.
- Prevalence file is release **20260806**; PrEP file is release **20260525** —
  same 2024 data year, different release dates.
- The **population denominator is unchanged** (total adult population, already
  inclusive of PLWH); PLWH are added to the **numerator only**.
- `uptake` and `kappa` are applied **identically to both groups** — an assumption:
  prescribing cadence in HIV care differs from PrEP care, and no data separates
  them.

## Global minimum across the ENTIRE grid (msm_frac = 1.00, 2024)

**Global min RR_needed = 1.03** — at uptake 0.55, kappa 5, R0 0.13, N 100000,
panel DEFF=1, state = DC. **This crosses below 1.42.** It is the single cell that
maxes every generous assumption simultaneously (the disowned best case); the
crossing was already present PrEP-only (panel DEFF1 best = 1.07). The **realistic
cell (panel DEFF1) = 6.31**, far above 1.42. Under single-comparison (no panel
independence) even the best cell stays above 1.42 (best cell 1.79 at msm 1.00).

## Verdict

The correction roughly halves the realistic-cell margin (PrEP-only panel
13.6–64.1 → 6.3–27.5 at msm 1.00) but the **realistic-cell verdict is unchanged**:
surveillance is infeasible under realistic conditions. Detection appears only in
the disowned best-case cell that compounds four implausible assumptions plus
optimistic panel independence.
