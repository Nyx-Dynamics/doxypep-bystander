# Reviewer & Editor Guide

**Manuscript.** *Monitoring That the Instrument Cannot Provide: Measurement Inheritance and
Tetracycline-Resistant Staphylococcus aureus in Doxycycline Post-Exposure Prophylaxis.*
Adrian C. Demidont, DO — Nyx Dynamics, LLC (Fairfield, CT) and Nyx Institute for
Computational Medicine (Philadelphia, PA). ORCID 0000-0002-9216-8569.

**What kind of paper this is.** An evidentiary-adequacy / measurement-inheritance analysis.
It makes **no causal or effect claim**. It asks whether the systems assembled around
doxy-PEP could *detect* a bystander tetracycline-resistant *S. aureus* signal if one
existed, and audits the three places an answer would have to come from — trials (A),
guidelines (B), surveillance (C). Every number and figure is regenerated from public data
by code in this repository.

## One-command reproduction

```
make all      # runs the test suite + regenerates every output, table, and figure
make pdf       # builds paper/manuscript.pdf (pandoc + citeproc + pdflatex)
```

Environment: Python 3.11 (pandas, statsmodels, scipy, matplotlib), pandoc + a TeX Live
`pdflatex`. No proprietary dependencies; no restricted-access data. `make all` runs 116
unit tests before regenerating outputs. Analysis decisions were logged with dates in
`DECISIONS.md` **before** results were known.

## What the paper does NOT claim (scope discipline)

- Not a **population-level** causal claim. The trial's own randomised, participant-level
  analysis of incident doxy-R *S. aureus* is significant (HR 3.89) and the paper accepts it;
  what the paper does **not** claim is that this individual-level signal propagates into a
  population externality — that is precisely what no deployed system can determine.
- Not that the harm is **unmeasurable in principle** — only that no *deployed* system can
  follow it; a system that could is specified affirmatively.
- The earlier aggregate "ratchet" reconstruction (per-carrier 8.5→40%, one-sided Fisher /
  Poisson) is **retired**: the trial performed the participant-level test itself; the interim
  denominators are kept only as a historical reporting-evolution exhibit.
- The analytic unit is *S. aureus* tetracycline/doxycycline resistance; MRSA appears only
  as a coded subset, and where the analysis is forced onto MRSA (clustering, denominator)
  this is stated and is itself an instance of the gap the paper describes.
