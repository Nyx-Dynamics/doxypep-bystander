# Deposit Bundle — Manifest

Package for pre-submission review and for the Zenodo deposit that accompanies the medRxiv
preprint and journal submission. Everything here is regenerable from the repository by
`make all` (analysis) and `make pdf` (manuscript); `make bundle` assembles this package and
writes `submission/CHECKSUMS.sha256`.

## What goes where

| Destination | Files |
|---|---|
| **Journal submission** (PLOS Biology Meta-Research) | `paper/manuscript.pdf`, cover letter, figures, Declarations (in-manuscript) |
| **medRxiv preprint** | `paper/manuscript.pdf` + link to the Zenodo/GitHub repository |
| **Zenodo deposit (citable DOI)** | the whole repository: code, coded source data, `paper/`, `outputs/`, `submission/` |
| **Reviewer/editor aids** | `submission/REVIEWER_GUIDE.md`, `submission/RESPONSE_TO_ANTICIPATED_REVIEWS.md` |
| **Author-internal (not submitted)** | `submission/PANEL_SYNTHESIS.md`, `submission/VENUE_MATRIX.md` |

## Bundle contents

### Manuscript
- `paper/manuscript.pdf` — typeset manuscript (19 pp, 5 figures; PLoS Biology format)
- `paper/manuscript.md` — pandoc source
- `paper/references.bib` — 15 cited entries, each verified against source text
- `paper/preamble.tex` — house LaTeX preamble

### Submission-facing documents (`submission/`)
- `COVER_LETTER.md` — to PLOS Biology Meta-Research; author block, no-causal-claim framing,
  reproducibility, disclosures
- `REVIEWER_GUIDE.md` — one-command reproduction + claim→artifact map + scope discipline
- `RESPONSE_TO_ANTICIPATED_REVIEWS.md` — ten anticipated objections answered, with the
  tet(K)/Liu 2011 verbatim rebuttal and every P0/P1 fix cross-referenced
- `VENUE_MATRIX.md` — venue-fit ranking and reframe cost (author-internal)
- `PANEL_SYNTHESIS.md` — six-reviewer adversarial panel synthesis + revision punch-list
  (author-internal)

### Figures (`outputs/figures/`)
- `three_streams.png` (Fig 1) — three streams, one reference line
- `streamc_linkage.png` (Fig 2) — Stream C linkage 2×2
- `feasibility_*.png` (Figs 3–5) — dilution / metro break-even

### Evidence & provenance (`outputs/`, repo root)
- `outputs/*_result.md` — one result doc per analysis (detectability, ratchet, σ, coverage,
  outbreak-fit, guidelines, streamc-linkage, feasibility, literature)
- `outputs/gap_register.md` — Introduction↔Methods claim alignment audit
- `outputs/citation_verification.md` — per-source claim-support check
- `outputs/streamb_denominator_reconciliation.md`
- `DECISIONS.md` — dated, pre-results analysis-decision log
- `data/raw/**/CHECKSUMS.md` — SHA-256 pins on every coded source

### Full-repository deposit (Zenodo)
- `submission/doxypep-bystander-repo.tar.gz` — the Zenodo research compendium
  (reproducibility artifacts only; no editorial/process layer). Generated by `make deposit`
  (2.0 MB); COPYFILE_DISABLE=1 + AppleDouble-excluded; contains an internal per-file
  `CHECKSUMS.sha256` manifest but **not** its own tarball checksum.
- `submission/doxypep-bystander-repo.tar.gz.sha256` — the tarball checksum, computed **after**
  the archive is closed and living **beside** it (never inside).
- `submission/REPO_DEPOSIT_README.md` — reproduce instructions + what is and is not included
- **Copyright:** the publisher PDFs/DOCX in `data/raw/papers/` and `data/raw/guidelines/`
  and the verbatim conference transcriptions are third-party works and are **excluded**; only
  their SHA-256 provenance pins (`CHECKSUMS.md`, `SOURCES.md`) travel. The analysis reads the
  coded YAML and public datasets, not the PDFs, so `make all` reproduces without them.

### Integrity
- `submission/CHECKSUMS.sha256` — SHA-256 over every file in the submission-facing bundle
  (generated by `make bundle`; verify with `shasum -c submission/CHECKSUMS.sha256`)
- Build order: `make all` → `make pdf` → `make bundle` → `make deposit` (deposit depends on
  bundle, so `make deposit` runs both).
